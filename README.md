# Atividade Prática - Programação em Java para Web

Aplicação web em Java para calcular o consumo anual de energia de uma lavadora de roupas a partir de 12 valores mensais.

## Funcionalidades
- Entrada do nome do aluno.
- Entrada do consumo (kWh) para os 12 meses.
- Soma do consumo anual.
- Identificação do mês de maior consumo.
- Identificação do mês de menor consumo.
- Tabela para comparação dos 12 meses.
- Validação de campos e de valores negativos.

## Executar no Windows
1. Instale o JDK 21.
2. Dê dois cliques em `run.bat`.
3. Acesse `http://localhost:8080`.

## Executar no Linux/macOS
```bash
./run.sh
```
Depois acesse `http://localhost:8080`.

## Publicar no Render
Este projeto contém `Dockerfile` e `render.yaml`. Após enviar os arquivos para um repositório no GitHub, crie um novo Web Service no Render usando o repositório. O Render detectará o Dockerfile e publicará uma URL pública.

Projeto desenvolvido para fins acadêmicos.
